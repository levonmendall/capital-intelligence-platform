# Complete active-investor loop

## Objective

The governed paper portfolio seeks to maximize long-term compounded return after
costs. The active-investor loop connects environment intelligence to capital
allocation without weakening evidence integrity, portfolio risk, or CIO authority.

The operating sequence is now:

```text
Global evidence and market observations
→ causal portfolio posture and regime transitions
→ investable views
→ certified view-to-expression ranking
→ six-specialist candidate analysis
→ CIO decision and bounded staged participation
→ independent portfolio construction
→ position lifecycle
→ reactive dependency monitoring
→ realized and prospective compounding accountability
```

## View-to-expression ranking

The system no longer stops at statements such as “risk-on,” “risk-off,” or “dollar
strength.” It turns each governed posture into one or more investment views and
compares certified instruments already present in the eligible universe.

Supported views include:

- productive risk;
- defensive duration;
- dollar strength;
- inflation protection;
- liquidity reserve; and
- diversified transition exposure.

Every expression is ranked using:

- directness of exposure;
- posture alignment;
- expected edge over the best capital alternative;
- capital-flow confirmation;
- market-expectations confirmation;
- liquidity;
- implementation cost;
- diversification value; and
- predictive-signal confidence.

Expression ranking cannot create an instrument or authorize capital. A ranked
expression must still pass the complete recommendation universe, specialist, CIO,
construction, and paper-execution process.

## Position lifecycle

Every evaluated candidate receives an explicit lifecycle state:

```text
observe
→ initiate
→ validate
→ add
→ hold
→ trim
→ exit
→ re-entry eligible
```

The lifecycle state is derived from the CIO action, current and constructed target
weights, living-thesis state, validation milestones, invalidation conditions,
monitoring indicators, and the candidate’s best certified expression score.

Lifecycle records are monitoring and CIO-review contracts. They do not execute trades
or convert a monitoring proposal into a portfolio action.

## Reactive monitoring

The system maintains dependency-level triggers for:

- capital-flow reversal;
- expectations-gap change;
- regime-transition probability change;
- rates and credit;
- volatility and breadth;
- earnings and guidance;
- thesis invalidation;
- superior replacement opportunities;
- portfolio risk-budget pressure; and
- catalyst completion or failure.

Candidate- or sleeve-specific changes request incremental reassessment. System-wide
regime changes request a full canonical cycle.

The live materiality scanner now evaluates the content and impact channels of new
public evidence in addition to price movement. Reliable and material changes in
growth, inflation, policy, liquidity, discount rates, earnings, credit, commodities,
currencies, volatility, positioning, regulation, geopolitics, operational risk,
cyber risk, climate, sentiment, or counterparty risk can request a CIO reassessment
without waiting for a large price move. Disputed, unverified, stale, fixture, or weak
records do not trigger the process.

## Compounding accountability

Each cycle persists prospective measures for:

- selected portfolio edge over the current portfolio;
- selected portfolio edge over cash;
- estimated cash opportunity cost;
- productive-risk deployment gap;
- positive-edge assets that remained unowned;
- construction improvement; and
- turnover and implementation drag.

These prospective measures complement the existing mature-horizon learning systems:

- point-in-time decision evaluation;
- decision calibration and value-added reports;
- gate-contribution analysis; and
- append-only missed-opportunity and avoided-loss outcomes.

Learning remains advisory. It cannot automatically lower a threshold, rewrite a
policy, create a candidate, or authorize capital.

## Persistence

View expressions, position lifecycle, reactive monitoring, and compounding
accountability are written to a separate append-only hash chain in the existing
journal database. Reusing the same event identifier with different content is
rejected. Updates and deletes are blocked by database triggers.

## Data coverage truth

The current capital-flow model uses certified point-in-time price and dollar-volume
behavior. It can distinguish accumulation, distribution, short covering, crowding,
rotation, and flow reversal, but it is not represented as complete institutional
flow.

The contracts are ready to incorporate certified sources for ETF and mutual-fund
flows, CFTC positioning, futures open interest, options surfaces and dealer exposure,
credit issuance, Treasury liquidity, cross-border capital, buybacks, and crypto
funding or exchange flows. Until those providers are licensed, configured, and
certified, the narrower coverage remains explicit.

## Protected authority boundaries

- One governed $250,000 paper portfolio remains.
- Exactly six specialists remain.
- The CIO remains the sole investment authority.
- Evidence and capability controls remain fail closed.
- Portfolio construction remains independently authoritative.
- Persistence remains append only and point in time.
- Execution remains paper only.
- No live-money capability is introduced.
