# Phase 1 PR Scope

This pull request is the first ordered implementation of issue #347.

It is intentionally limited to economic-qualification consistency:

- preserve participation and exploration as research lanes;
- prohibit positive canonical capital when absolute return, success probability, robust edge or stressed edge fails;
- prohibit CIO sizing from using robustness soft-failure bypasses;
- retain holding review, evidence vetoes, downside, liquidity, funding, implementation and construction controls;
- add deterministic regression coverage.

The broader currency, structural-theme, business, trend, risk, construction-reconciliation and calibration work remains in the ordered program and is not silently introduced in Phase 1.
