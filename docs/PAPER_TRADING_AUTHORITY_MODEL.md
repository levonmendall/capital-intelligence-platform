# Paper-Trading Authority Model

Controlled paper execution requires three independent, non-substitutable layers:

1. **Human entry authority** — the existing controlled paper-test eligibility package and human release decision approve one exact baseline and named cohort.
2. **Operational launch certification** — sustained live cycles, provider health, execution calibration, reconciliation, recovery, and portfolio invariants must remain current.
3. **Runtime risk switch** — the append-only active/halted control is an emergency operating switch. It cannot approve entry and cannot substitute for the human decision or launch certification.

Paper execution proceeds only when all three match the exact baseline, investment-process version, and code version. A suspension, revocation, blocked or expired launch assessment, runtime halt, or version mismatch blocks execution.

No layer authorizes real money, broker connectivity, custody, live orders, or performance claims.
