# Surface accessibility

The four command surfaces use different color, geometry, and motion, but page meaning never depends on color alone.

- Every surface has a unique written title, purpose statement, and process story.
- Metric labels and values remain text-first.
- Motion is decorative and does not carry decision authority.
- Tables, expanders, and navigation retain familiar Streamlit behavior.
- Mobile layouts collapse into a linear reading order.
- Status and governance language remain explicit in every appearance mode.

The interface keeps the signature operating-system markers while ensuring the distinction between Today, Environment, Portfolio, and History remains understandable without animation or color perception.
