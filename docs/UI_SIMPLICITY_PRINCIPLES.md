# UI simplicity principles

The interface may become more sophisticated only when the change improves orientation, comprehension, or confidence without increasing the number of decisions required from the user.

## Governing principles

1. **One purpose per surface.** Today, Environment, Portfolio, and History each answer a different question.
2. **One dominant conclusion.** The most important portfolio-level message appears before supporting detail.
3. **Progressive disclosure.** Audit evidence, tables, and implementation detail remain available without competing with the primary conclusion.
4. **Consistent navigation.** Page identity changes, but location, terminology, and interaction patterns remain predictable.
5. **Visual distinction without visual noise.** Color, geometry, motion, and hierarchy communicate purpose; they do not decorate every element.
6. **Governance remains visible.** Interface sophistication cannot imply authority that the underlying decision, construction, or paper-execution layer does not possess.
7. **Mobile remains first-class.** Surface stories, metrics, capital maps, and activity trails collapse into a clear single-column reading order.

The continuing product principle is: The interface stays quiet until evidence earns attention.
